# Bakanime - Mobile App

**Bakanime** est une application mobile dédiée aux fans d'animation japonaise. Elle permet de découvrir et de suivre les dernières séries et films animés, le tout dans une interface simple et intuitive.

Ce projet est **personnel** et c'est ma **première application mobile** que je développe. L'application a été créée avec **Flutter**, ce qui permet une compatibilité multiplateforme, offrant une expérience fluide sur iOS et Android.

## 🌐 Site Web

Vous pouvez également accéder à une version du web sur [Bakanime](https://diangou.github.io/bakanime_application-mobile.github.io//) (notez que l'expérience web peut être limitée, et il est recommandé d'ouvrir le lien de l'application mobile sur un téléphone pour une meilleure expérience).

## 📱 Meilleure expérience sur mobile

L'application est principalement conçue pour une utilisation mobile. La version web est disponible, afin d'ouvrir le lien sur un téléphone mobile pour simuler l'expérience de l'application mobile. Le site web ne reflète pas pleinement les fonctionnalités et l'interface mobile optimisée.

## 🚀 Installation de l'application mobile

1. Clonez ce dépôt :

   ```bash
   git clone https://github.com/Diangou/bakanime_application-mobile.git
   
2. Ouvrez le projet avec Android Studio ou Visual Studio Code.

3. Assurez-vous d'avoir Flutter installé et configuré. Si ce n'est pas déjà fait, suivez les instructions d'installation de Flutter ici.
  
4. Exécutez l'application : flutter run

## 💡 Fonctionnalités fictives

- Découvrez une large collection d'animations japonaises.
- Suivez vos séries et films préférés.
- Interface fluide et réactive pour une meilleure expérience mobile.
- Notifications de mise à jour des épisodes pour rester à jour.
